Formatting, not rewriting.

Your text is the source of truth. TPS Agent does not rewrite, translate, correct, summarize, or reorder it. Remove the TPS markup and the original words, punctuation, language, and order remain.

The Agent edits the document around your text, not the text itself. A lossless recovery check confirms that removing TPS markup returns the original words in the original order.

  • StructureSegments and blocks that follow the ideas already present in your text.
  • DeliveryPacing, pauses, emotion, emphasis, energy, and speaker cues.
  • Source preservedSpelling, punctuation, language, numbers, quotations, and order remain unchanged.

Format the text you already have.

Use TPS Agent when the words already exist and the next job is performance: clear teleprompter structure, deliberate pacing, and delivery guidance.

  • Speeches & keynotesTurn a speech draft into a paced teleprompter document without changing the speech.
  • Video scriptsAdd beats, pauses, emphasis, and energy cues for confident on-camera delivery.
  • Presentations & demosOrganize transitions, speaker turns, and key messages for a natural read.
  • Lessons & webinarsBreak long explanations into readable segments with natural breathing room.
  • Podcasts & voice-overDirect tone, rhythm, pronunciation, and emphasis while keeping the copy intact.
  • Dialogue & multiple speakersPreserve every line while adding speaker-aware structure and delivery cues.

From source text to valid TPS.

The workflow is intentionally narrow: preserve the copy, add performance direction, validate the document.

  • Send source textPaste the exact text you want to preserve and add any pacing, tone, speaker, or duration constraints.
  • Add TPS directionThe Agent maps topic shifts and delivery intent, then adds only valid TPS headers, tags, cues, and escapes.
  • Validate preservationTPS syntax is checked, then a recovery audit verifies that removing markup reconstructs the source text exactly.

Why TPS instead of plain text or subtitles?

Plain text stores words. SRT and WebVTT time captions. TPS is designed for live teleprompter delivery, where pace, pauses, emotion, emphasis, and speaker intent matter.

What is TPS?

TPS (TelePrompterScript) is an open, Markdown-based file format for teleprompter scripts. It keeps scripts readable in any text editor while giving compatible teleprompter software structured pace, timing, pauses, emotion, emphasis, and speaker cues.

It is human-readable like Markdown and structured enough for validators, compilers, teleprompter players, editors, and SDKs.

The Agent formats the text. The TPS standard defines the document it returns.

Before you connect.

Everything the Agent changes—and everything it must leave alone.

Does TPS Agent write or rewrite my text?

No. It formats the text you supply. It does not paraphrase, translate, correct, shorten, expand, censor, or reorder source copy.

What kind of text can I format?

Speeches, presentations, video scripts, lessons, webinars, podcasts, voice-over copy, dialogue, and other text intended to be spoken.

What does the Agent add?

Valid TPS structure plus pacing, pauses, emotion, emphasis, energy, pronunciation, and speaker cues when supported by the text or your instructions.

Can I request a target duration?

Yes, as a pacing constraint. If the unchanged text cannot fit, the Agent preserves it and asks whether you want to change the duration or revise the source.

Is the result compatible with PrompterOne?

Yes. PrompterOne is an open-source editor, rehearsal studio, and teleprompter that implements the TPS format.

How do I connect TPS Agent?

Use the published Streamable HTTP MCP endpoint from an MCP-capable client. Send source text and receive one complete TPS document.

Does it preserve Ukrainian and other languages?

Yes. The Agent preserves the source language and text exactly while adding TPS markup around it.
